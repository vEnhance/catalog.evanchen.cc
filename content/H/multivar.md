Like all higher math units, consists of:
- A **syllabus** of ten-ish topics to learn about.
- Recommendations for **texts** to learn these topics from.
  These range from classic textbooks,
  [Napkin chapters](https://web.evanchen.cc/napkin.html),
  even YouTube videos.
- A prompt to write a **blog post** about what you learned.
  The blog post should cover the major definitions and theorems,
  lots of examples, philosophical comments,
  and worked exercises that cover everything in the syllabus.
  It's encouraged (but not required) to be public,
  and it can be in any format (like AoPS blog post, PDF, or Overleaf link).
- Several **walkthroughs**. (Ideally? Right now only GRF has them.)
- A running list of previous blog posts
  that other otters have volunteered to be listed.
- Several **practice problems**,
  one being a required, 9-club, "write a blog post" problem.
